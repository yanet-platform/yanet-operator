## Operator 3.0.1 / Helm chart 0.2.1

### Workload preservation during cordon

Cordoned nodes matching `Yanet.spec.nodeSelector` remain in the desired set.
Previously, excluding unschedulable nodes could cause their existing Deployments
to be pruned as orphans. Cordon and uncordon alone now leave those Deployments
unchanged. Explicit installation disablement, selector changes and deletion
retain their existing semantics.

### Standard gateway endpoint environment

Managed HostPath configuration now receives standard `xcfg.WithEnv()` variables
`YANET_GATEWAYS_<index>_ENDPOINT` instead of the custom
`YANET_KUBERNETES_GATEWAYS` JSON variable. Runtime images must support the
standard environment loader.

Prepare host configuration with the correct active gateways in ascending
physical NUMA order before upgrading. Indices address positions in that list,
not physical NUMA IDs: a list containing only `numa1` uses
`YANET_GATEWAYS_0_ENDPOINT` for its `controlplane-numa1` Service. The operator
overrides endpoints only; gateway names, TLS settings and membership stay in
the host configuration. Other schemas require explicit schema-specific palette
overrides. Inline ConfigMaps remain opaque to automatic network environment
injection.

### Upgrade and validation

- No API/CRD reset is required when upgrading from operator 3.0.0 / chart 0.2.0.
- Updating the generated environment from the old JSON variable can roll runtime
  Pods when `autoSync` is enabled. Schedule this configuration transition explicitly;
  the cordon fix does not suppress intentional Pod-template updates.
- Upgrades from pre-3.0 installations still require the
  [3.0.0 replacement procedure](v3.0.0.md).
- Regression coverage verifies unchanged Deployment identity and resource version
  through cordon, repeated reconciliation and uncordon with a real API server.
- Runtime tests cover dense gateway indices, sparse physical NUMA IDs and
  preservation of unrelated TLS environment settings.

Local and CI tests do not establish target-cluster packet-forwarding continuity.
