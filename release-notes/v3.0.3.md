# Operator and chart 3.0.3

This release fixes final workload rendering so explicit installation overrides
take precedence over shared palette patches. Operator and chart versions remain
aligned, with separate image and chart OCI repositories.

## Fixed

- Explicit component `enabled: true` forces one replica after palette patches;
  `enabled: false` and installation-wide disable force zero. Omitting component
  enablement preserves inherited replica patches, including standby presets.
- Explicit installation container image names/tags and native-sidecar image
  overrides win later palette patches. Unrelated patched environment, resources
  and container images remain intact.
- Stale image overrides for containers removed from an operator's palette no
  longer prevent rendering the remaining declared containers.
- Resolved dataplane hugepage requests and limits survive resource patches,
  without retaining conflicting page-size keys. Unrelated CPU and ordinary
  memory resources remain unchanged.

## Per-installation hugepages

`Yanet.spec.components.dataplane.hugepages` can replace the palette reservation
for one installation. Omitted/null inherits the palette; a supplied object
replaces the whole reservation. A size with omitted/zero count selects that
node's allocatable pool; a positive count selects an explicit reservation.
For example, `{size: 2Mi, count: 1024}` reserves 2Gi.

## Upgrade

The Kubernetes API remains `yanet.yanet-platform.io/v1alpha1`; no CRD reset is
required for 3.0.x installations. Apply the updated CRD schemas before using the
per-installation hugepages field. Helm does not upgrade CRDs in `crds/`
automatically.

Before updating the controller, audit explicit installation enablement and image
overrides that were previously masked by palette patches. With `autoSync: true`,
an explicit `enabled: true` now starts a workload even when its preset patches
specify zero replicas, and explicit image overrides can trigger Pod rollouts.
To retain inherited standby behavior, omit the component enablement override;
to keep the component disabled explicitly, use `enabled: false`.

Review hugepage reservations that also use resource patches: the resolved typed
reservation now takes precedence over conflicting hugepage resource keys.
Use typed palette or installation hugepages settings for the intended pool and
count. The operator does not provision hugepages on the host.

Native-sidecar composition and managed network ownership guards are preserved.
Pre-3.0 installations still require the [3.0.0 replacement procedure](v3.0.0.md).
Unit, rendering and envtest results do not establish forwarding or hardware
behavior on a target node.
